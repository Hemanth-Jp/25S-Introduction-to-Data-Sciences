\addcontentsline{toc}{chapter}{AI Tool Usage Declaration}

This assignment was conducted independently by the authors, with partial non-evaluative assistance from the AI tool \textbf{Claude (Anthropic)}. The AI was used exclusively to improve code readability, structure the documentation, and clarify statistical concepts without influencing the analysis outcomes or conclusions.

\section*{Scope of AI Involvement}
The AI assistance was limited to the following tasks:
\begin{itemize}
	\item \textbf{Code Commenting \& Formatting:} Adding explanatory comments to R code and organizing sections for clarity.
	\item \textbf{Report Structuring:} Formatting LaTeX sections and suggesting suitable academic tone and transitions.
	\item \textbf{Statistical Concept Clarification:} Providing plain-language explanations of statistical assumptions, diagnostic interpretations, and regression test summaries.
	\item \textbf{Visualization Design:} Advising on suitable plots and best practices for visual data representation in R.
\end{itemize}
