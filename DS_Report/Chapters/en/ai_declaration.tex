\chapter*{AI Tool Usage Declaration}
\addcontentsline{toc}{chapter}{AI Tool Usage Declaration}

In completing this assignment, we made limited use of the AI tool \textbf{Claude (Anthropic)} to support non-evaluative aspects of our work. Our use of the tool was strictly to improve clarity, structure, and presentation—never to substitute or replace our understanding, analysis, or interpretation.

\section*{How We Used AI}
We used Claude in the following ways:
\begin{itemize}
	\item \textbf{Code Commenting and Formatting:} We asked for help adding explanatory comments to sections of our R script to improve code readability and documentation.
	\item \textbf{Structuring and LaTeX Formatting:} We received suggestions on how to organize sections of our report more effectively and how to write certain passages in a formal academic tone using LaTeX.
	\item \textbf{Concept Clarification:} We used Claude to better understand some statistical concepts (e.g., regression assumptions and diagnostics) to ensure we applied and interpreted them correctly.
	\item \textbf{Visualization Advice:} We asked for ideas on the most appropriate graphical methods to represent distributions and classification performance.
\end{itemize}
